# Saved routes (bundled)

Verified route cards, one file per country, sector and problem. Format and reuse rules: [`../references/saved-routes.md`](../references/saved-routes.md). No personal data.

Every country starts empty and is filled by real use: the lead saves each verified card to the user's `portal-pilot/routes/` folder, and contributors send good ones here. For India, the `grievance-agent` skill already carries deep, sector-by-sector routes.
