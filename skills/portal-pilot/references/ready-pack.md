# The ready pack

Rung 3 of the result ladder. A single file, `pack.md`, in the case folder, written **before** any portal is opened. With it, the user can file alone in about ten minutes, on any device, with no agent. It is also what survives when a portal blocks the agent, a session dies, or the user runs out of time.

Write it for someone who has never seen the portal. Plain words, the user's language, no jargon.

```
# READY PACK: [task in one line]
Prepared: YYYY-MM-DD    Good until: [date the rules were checked + when to re-check; or the deadline]

## Where
[Body name] — [official URL, verified]
Beware: [look-alike sites, fake helplines, paid agents for this body]

## Have ready
- [phone that receives the OTP]
- [each file to upload: name, format, size limit]
- [payment method and amount, if any]

## Steps
1. Open [URL]. Click "[exact button text]".
2. YOUR GATE: [what to type or tick, e.g. "type the code in the picture, tick the consent box, press Next"].
3. In "[field label]", type: [value]        ← masked values shown as "your full account number (ends 4417)"
4. In "[field label]", choose: [option]
5. In "[text box label]", paste TEXT A below.
6. Upload [file] under "[label]".
7. Check every value against this pack. Press "[submit button text]".
8. Save the acknowledgement: screenshot it and note the reference number.

Steps the agent has not walked itself are marked (not yet seen: follow the page).

## TEXT A: [what it is]
[the drafted text, already passing the portal's length and character rules]
Checked: [limit and character rule applied] — PASS

## If the portal fails
[The offline route: email or postal address of the right officer, verified, with the letter below.]

## After you file
Reference number goes here: ________
Next: [what happens, by when, and what to do if it doesn't] — next date: YYYY-MM-DD
```

Rules:
- Every value comes from the confirmed field sheet. Nothing invented.
- Full identity or account numbers never appear in the pack; describe them ("your full PAN") so the user types them. Inside drafted text, use a visible slot in allowed characters, like `(TYPE YOUR FILE NUMBER HERE)`, and add a step: "Replace every (TYPE ... HERE) before you submit."
- Mark the source and check date of every rule, deadline and fee. UNVERIFIED items stay labelled.
- For rung 4, add the complete letter or email, addressed and ready to send, with the list of enclosures.
- Update the pack if the plan changes. An out-of-date pack is worse than none.
